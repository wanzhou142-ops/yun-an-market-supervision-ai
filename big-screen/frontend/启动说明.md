# 前端启动说明（云安市场监管普法助手 · 大屏）

> 适用：Windows 下用 **Git Bash** 或 **WorkBuddy 终端**（本质都是 bash）启动本项目。
> 项目目录：`E:\xiaozhi-Requirement\big-screen\frontend`

---

## ⚠️ 最重要的一条：不要直接 `npm run dev`

在本环境（Git Bash / WorkBuddy 终端）里直接跑 `npm run dev` 会**崩溃**，报错类似：

```
Error: [safe-delete] 操作失败 ... .next/app-build-manifest.json ... trash 操作 ...
```

原因：WorkBuddy 的「安全删除」垫片（`NODE_OPTIONS` 里注入的 `genie-safe-delete.cjs`）会拦截 Next.js 启动时的缓存清理，导致崩溃。
**解决办法：用本项目自带的 `dev.sh` 启动器**，它会先关掉那个垫片再启动，已验证可正常跑起来。

---

## 启动步骤（照做即可）

**第 1 步：打开终端**
用 Git Bash，或 WorkBuddy 里的终端。

**第 2 步：进入项目目录**
```
cd /e/xiaozhi-Requirement/big-screen/frontend
```
（也可在资源管理器进到 `E:\xiaozhi-Requirement\big-screen\frontend`，空白处右键「Git Bash Here」，自动在该目录打开。）

**第 3 步：首次拉取才需要装依赖**
如果依赖已装好（目录里有 `node_modules`）可跳过；如果是刚从 git 拉下来第一次跑，先执行一次：
```
npm install
```

**第 4 步：启动（关键）**
```
bash dev.sh
```
就这一行。它会自动 `unset` 掉安全删除垫片变量，再 `npm run dev`。

**第 5 步：等编译完成**
首次编译约 **1~3 分钟**。终端出现下面这行才算就绪：
```
 ✓ Ready in XX.Xs
```
没看到这行前别急着开网页（此时访问会连接失败，属正常）。

**第 6 步：浏览器打开三个场景**
同一套页面靠 URL 参数 `?scene=xxx` 切换：

| 场景 | 网址 |
| --- | --- |
| 迎宾大厅（默认） | `http://localhost:3000/?scene=welcome` |
| 宣传廊 | `http://localhost:3000/?scene=corridor` |
| 模拟药店 | `http://localhost:3000/?scene=pharmacy` |

（不带参数直接开 `http://localhost:3000/` 就是迎宾大厅。）

**停止服务**：回到终端按 `Ctrl + C`。

## 常见问题

**Q：我用 `npm run dev` 崩了，怎么办？**
A：关掉终端重开，改用 `bash dev.sh` 启动即可，不用改任何代码。

**Q：提示 `npm: command not found`？**
A：说明当前终端找不到 Node。请确认装了 Node.js，且在 Git Bash / WorkBuddy 终端里操作（不要用系统的纯 cmd 双击 `dev.bat`，那里面通常没有 node）。

**Q：改了代码要重启吗？**
A：开发模式（dev）会自动热更新，一般不用重启；只有改了 `.env.local` 才需要 `Ctrl+C` 后重新 `bash dev.sh`。
