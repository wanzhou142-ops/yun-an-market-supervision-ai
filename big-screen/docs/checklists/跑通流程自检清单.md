# 跑通流程自检清单（可独立操作）

> 目标：不依赖他人，自己走一遍端到端流程，确认两个平台都能正常跑。
> 用法：每跑完一步在 `[ ]` 前打 `x`，全部跑完把结果截图发给助手看。

---

## 一、小智（教学考，唯一用途）自检

准备：小机器人已联网、麦克风可用、已贴总控版角色介绍

### 问模式
- [ ] 对机器人说："药品和非药品怎么区分？"
- [ ] 预期：引用《药品管理法》某条作答，带"根据第X条"
- [ ] 判断：✅ 答出法条 / ❌ 答非所问（回看角色介绍是否贴对）

### 学模式
- [ ] 对机器人说："我想学化妆品标签的规定"
- [ ] 预期：用大白话讲解 + 举例，不是干巴巴甩法条
- [ ] 判断：✅ 讲解风格 / ❌ 仍是问答风格（回看学模式触发条件）

### 考模式（重点测 ABCD 发音容错）
- [ ] 对机器人说："我要考试"
- [ ] 预期：先说"共5题，3选择+2判断"，然后逐题出
- [ ] 选择题用语音回答，故意换说法测容错：
  - [ ] 说"选A" → 应判 A
  - [ ] 说"第二个" → 应判 B
  - [ ] 说"必"（B 谐音）→ 应判 B
  - [ ] 说"第三个" → 应判 C
- [ ] 判断题：说"正确" / "不对" → 应正确判分
- [ ] 5 题答完 → 给总分（如"你答对4题，得分80分"）
- [ ] 若仍频繁误判 → 把选项标号改"甲乙丙丁"重测（改提示词【考试结构】与【出题格式】）

## 二、Dify（迎宾 / 宣传廊 / 模拟药店，全部场景）自检

准备：登录 `zkt.medlibbot.com:8380`，应用已建、知识库已挂、模型 DeepSeek-V3

### 文字对话跑通
- [ ] 打开应用「预览 / 调试」对话框
- [ ] 输入："药品和非药品怎么区分？"
- [ ] 预期：引用《药品管理法》条文，带引用标记
- [ ] 判断：✅ 命中知识库 / ❌ fallback（回看知识检索节点 + context 变量）

### 多场景覆盖（验证语义检索，不只关键词）

- [ ] 输入："无证经营食品怎么处罚？" → 应命中食品安全法
- [ ] 输入："医疗器械注册证怎么办理？" → 应命中器械条例

### 模型确认
- [ ] 确认 LLM 节点模型是 DeepSeek-V3
- [ ] 确认无报错（若报"模型不存在" → 找管理员配 V3 key）

## 四、卡住时的快速定位

| 现象 | 可能原因 | 动作 |
|------|---------|------|
| 小智答非所问 | 角色介绍没贴对 | 重新贴总控版角色介绍 |
| 小智 ABCD 误判 | 发音 / ASR 偏差 | 用"第二个"等说法；仍不行改甲乙丙丁 |
| Dify 答"找不到条文" | 知识库没挂 / 检索没命中 | 查知识检索节点 + context 变量 |
| Dify 模型报错 | V3 未配 | 找管理员配 DeepSeek-V3 key |
| 某场景搜不到 | 用了关键词模式 | 确认知识库是「高质量 + 混合检索」 |
