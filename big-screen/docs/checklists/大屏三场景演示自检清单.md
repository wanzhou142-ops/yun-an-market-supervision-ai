## 三、推荐演示动线（给经理/客户看的顺序）

1. **迎宾大厅** → 先演示多轮迎宾（问姓+记住），再演示一个法规问答+TTS 朗读，体现「会迎客、会讲解、会说话」。
2. **宣传廊** → 切 URL 参数，演示普法知识随问随答，体现「宣传内容可交互」。
3. **模拟药店** → 切 URL 参数，演示违法违规点查询，体现「实训/科普场景」。

> 切换方式：浏览器地址栏改 `?scene=welcome/corridor/pharmacy` 回车即可（已知小瑕疵：首屏会先闪一下 welcome 再定位到目标场景，约 0.5s，演示时建议直接以目标场景地址打开）。
