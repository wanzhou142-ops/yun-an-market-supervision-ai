# 09 · 导航触发表（按场景）

> 对应需求：梳理大屏导览**从哪到哪、怎么触发、播什么口播**，便于联调与验收。  
> 核心代码：`lib/tour-nav.ts`（状态/chips/classify/defaultNext）、`app/page.tsx`（navigateTo / switchScene）。

## 一、总览：三个主场景

```
  迎宾大厅 ←──────────────────────────────→ 宣传廊
      ↑                                        ↑
      └──────────── 模拟药店 ←─────────────────┘
```

| 全局操作 | 效果 | 口播 |
|----------|------|------|
| 顶栏 tab 切主场景 | 跳到对应场景总览 | 切**迎宾** = 静默；切宣传廊/药店 = 对应 enter |
| 「结束互动」 | 回视频模式循环播迎宾 | 无 |
| 35s 无操作（空闲回退） | 本场景内逐级回退 | **静默**（`applyNavSilent`） |

## 二、迎宾大厅

面包屑：`迎宾大厅`

### 2.1 视频模式（待机）

| 去哪 | 触发 | 口播 |
|------|------|------|
| 进入交互 | 点「开始互动」 | `welcome.intro` → 播 intro 视频 |
| 切宣传廊 / 药店背景 | 底部 tab | 无（只换背景视频） |

### 2.2 交互 · 三选一（`choice_ready`）

**屏幕按钮：** 宣传廊 · 模拟药店 · 综合培训区（`welcomeChoiceChips`）

| 去哪 | 触发 | 口播 |
|------|------|------|
| 宣传廊总览 | 按钮 / 说「宣传廊」 | `corridor.enter` |
| 药店总览 | 按钮 / 说「模拟药店」 | `pharmacy.enter` → `pharmacy.choice` |
| 培训区（不跳转） | 按钮 / 说「综合培训」 | `training.pointer` |
| 15s 无选择 | 自动（`defaultNext`） | → 宣传廊 `corridor.enter` |

### 2.3 从其他场景回到迎宾

| 从哪回来 | 触发 | 口播 |
|----------|------|------|
| 宣传廊 / 药店总览 | 按钮「返回迎宾」/ 说「回迎宾」 | `welcome.choice` |
| 顶栏点「迎宾大厅」 | tab（`switchScene(welcome)`） | **静默**（回 standby，不播） |

## 三、宣传廊

面包屑示例：`宣传廊 · 化妆区 · 科普篇`（`locationTrail`）

### 3.1 总览（无子区 `aspect=null`）

**按钮：** 化妆区 · 药品区 · 器械专区 · 模拟药店 · 返回迎宾（`corridorOverviewChips`）

| 去哪 | 触发 | 口播 |
|------|------|------|
| 化妆区 | 按钮 / 说「化妆品」 | `corridor.cosmetic` |
| 药品区 | 按钮 / 说「药品」 | `corridor.drug` |
| 器械专区 | 按钮 / 说「器械」 | `corridor.device` |
| 药店总览 | 按钮 / 说「模拟药店」 | `pharmacy.enter` |
| 迎宾三选一 | 按钮 / 说「回迎宾」 | `welcome.choice` |
| 15s 无选择 | 自动 | → 化妆区 |

**进入总览时的口播（`scriptIdForNav` + `isCorridorReturn`）：**

| 从哪来 | 口播 |
|--------|------|
| 迎宾首次 / 跨主场景 | `corridor.enter`（长介绍） |
| 子区说「返回」/「返回宣传廊」 | `corridor.return`（短引导） |
| 药店跨过来 | `corridor.enter`（非 return） |

### 3.2 专区（化妆 / 药品 / 器械）

**按钮：** 科普篇 · 法规篇 · 案例篇（可跨区换专区）

| 去哪 | 触发 | 口播 |
|------|------|------|
| 科普篇 | 按钮 / 说「科普」 | `corridor.{区}` → **播科普视频** |
| 法规篇 | 按钮 / 说「法规」 | `corridor.{区}` → **播法规视频** |
| 案例篇 | 按钮 / 说「案例」 | `corridor.{区}.case` |
| 换其他专区 | 按钮 / 语音 | 对应 `corridor.{区}` |
| 宣传廊总览 | 说「返回」 | `corridor.return` |
| 15s 无选择 | 自动 | → 科普篇 |

### 3.3 案例选择（`chapter=casePick`）

**按钮：** 案例一 · 案例二

| 去哪 | 触发 | 口播 |
|------|------|------|
| 案例一 / 二 | 按钮 / 语音 | 案例引导 → **播案例视频** |
| 篇章选择 | 说「返回」 | 回到专区选篇章（无 enter/return） |

### 3.4 视频播完（`uiPhase=postContent`）

**口播：** `corridor.post.{区}.{篇章}`

**按钮：** 其他篇章 · 其他专区 · 返回宣传廊 等

| 去哪 | 触发 | 口播 |
|------|------|------|
| 同区其他篇章/专区 | 按钮 / 语音 | 正常 navigate 口播 |
| 15s 无选择 | 自动（`postContentTimeoutPatch`，静默） | 回到同层 choosing |

## 四、模拟药店

面包屑示例：`模拟药店 · 传统药房 · 药品区 · 处方药区`

### 4.1 总览（无子模式 `pharmMode=null`）

**按钮：** 传统药房 · 新零售 · 宣传廊 · 返回迎宾（`pharmacyOverviewChips`）

| 去哪 | 触发 | 口播 |
|------|------|------|
| 传统药房 | 按钮 / 说「传统」 | `pharmacy.traditional` |
| 新零售 | 按钮 / 说「新零售」 | `pharmacy.newretail` |
| 宣传廊总览 | 按钮 / 说「宣传廊」 | `corridor.enter` |
| 迎宾 | 按钮 / 说「回迎宾」 | `welcome.choice` |
| 15s 无选择 | 自动 | → 传统药房 |

**进入总览时的口播（`scriptIdForNav` + `isPharmacyReturn` + `shouldPlayPharmacyChoice`）：**

| 从哪来 | 口播 |
|--------|------|
| 迎宾首次 | `pharmacy.enter` + `pharmacy.choice` |
| 子区说「返回」 | `pharmacy.return` |
| 宣传廊跨过来 | `pharmacy.enter`（不播 choice） |

### 4.2 传统药房 / 新零售

| 去哪 | 触发 | 口播 |
|------|------|------|
| 传统 → 药品区 / 非药品区 | 按钮 / 语音 | `pharmacy.traditional.drug` / `nondrug` |
| 新零售 → 各叶子区 | 按钮 / 语音 | 对应叶子引导 → **播视频** |
| 药店总览 | 说「返回」 | `pharmacy.return` |

### 4.3 传统药房 · 叶子区（处方 / OTC / 中药…）

| 去哪 | 触发 | 口播 |
|------|------|------|
| 某叶子区 | 按钮 / 语音 | `pharmacy.leaf` → **播视频** |
| 上一级 | 说「返回」 | 回到 area 选择（无 return 口播） |

### 4.4 视频播完（`postContent`）

**口播：** `pharmacy.post.leaf`

| 去哪 | 触发 | 口播 |
|------|------|------|
| 同层其他叶子 | 按钮 / 语音 | 正常 navigate |
| 15s 无选择 | 自动（静默） | 回到 choosing |

## 五、语音关键词（跨场景）

| 说法 | 效果 |
|------|------|
| 回迎宾 / 回首页 / 迎宾大厅 | → 迎宾 `welcome.choice` |
| 宣传廊 / 走廊 / 展区 | → 宣传廊总览 |
| 模拟药店 / 药店 / 药房 | → 药店总览（在药店内说「宣传廊」则跳宣传廊） |
| 返回宣传廊 / 回宣传廊 | → 宣传廊总览（仅 chapter 层生效） |
| 返回 / 回去 | **本场景内**回上一级；已在最顶层总览 → 迎宾 |
| 综合培训 / 培训区 | 只播 `training.pointer`，不跳转 |

近音纠错（`correctAsrText`）：宣传狼/朗→宣传廊，模型药店/模拟药品→模拟药店。

## 六、口播类型速查

| 类型 | 何时播 |
|------|--------|
| `*.enter` | 第一次从迎宾进入，或跨主场景进入 |
| `*.return` | 从本场景**子层级**回到该场景总览（不含跨场景） |
| `pharmacy.choice` | 仅迎宾 → 药店（`enter` 后紧接） |
| `corridor.post.*` / `pharmacy.post.*` | 内容视频播完后 |
| 静默 | 空闲 35s 回退、post 15s 超时、顶栏切迎宾、welcome→welcome |

## 八、验收自检要点

1. 宣传廊子区 → 说「返回」→ 播 `corridor.return`，**不是** `corridor.enter`。
2. 药店子区 → 说「返回」→ 播 `pharmacy.return`。
3. 宣传廊 ↔ 药店跨场景 → 播 enter，**不是** return。
4. 迎宾 → 药店 → 播 `enter` + `choice`；宣传廊 → 药店 → 只播 `enter`。
5. 跨场景跳转时背景/内容视频应静音，避免双声道（`stopVoiceAndPlayback` / `bgVideoMuted`）。
6. 顶栏切迎宾 = 静默，不重复播 `welcome.choice`。
