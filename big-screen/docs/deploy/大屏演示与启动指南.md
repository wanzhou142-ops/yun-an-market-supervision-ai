# 云安区市场监管 · AI 普法大屏 —— 演示与启动指南

> 适用对象：自己本地演示 + 发给客户现场演示
> 对应程序：`dify-frontend/deploy/`（一键启动包，自带运行时，无需安装 Node、无需构建）

---

## 一、包里有什么（一句话）

大屏三场景（迎宾大厅 / 宣传廊 / 模拟药店）的演示前端，含数字人语音/文字交互。
双击就能跑，**不需要装任何环境**。

---

## 二、你自己怎么打开（本地演示）

### ✅ 方式 1：双击启动（最省事，现场推荐）

1. **先确认 3000 端口没被占用**（最常见翻车点）
   - 如果之前用开发模式（`dev.sh`）跑过，要先把它关掉；
   - 其他占 3000 的程序（比如另一个演示包）也要关掉。
2. 进入 `dify-frontend/deploy/` 文件夹，**双击 `start.bat`**。
3. 等约 **5 秒**，Chrome 会自动**全屏**打开迎宾大厅，背景视频**带声音**播放。
4. 结束演示：关掉 Chrome 标签页 + 关掉那个黑色命令行窗口（`server`）。

### 方式 2：手动起服务、自己开浏览器

进 `deploy/` 目录，双击 `start.bat`（或命令行 `node.exe start.cjs`），
然后浏览器打开 `http://localhost:3000` 即可。

### 方式 3：开发模式（改代码调试用，**不用于现场**）

项目根 `dify-frontend/` 下运行 `bash dev.sh`，浏览器开 `http://localhost:3000`。
需本机装有 Node，且可能因首次编译慢而短暂打不开。

## 三、界面怎么操作（讲解员看这里）

| 状态 | 画面 | 能做什么 |
|------|------|----------|
| **视频模式**（默认） | 全屏播背景视频 + 原声 | 底部正中三个标签 **迎宾大厅 / 宣传廊 / 模拟药店**，点一下切换场景视频（带声）；右下角有 **「开始互动」** 按钮 |
| **数字人接待**（点「开始互动」后） | 数字人出现，背景视频变静音 | 顶栏出现标题 + 三标签；左下角 **「返回视频」** 可退回视频模式；可语音/文字向数字人提问（普法、培训、考核） |

- **子分区入口**：进入数字人界面后，宣传廊可切「器械 / 化妆品 / 药品」，模拟药店可切「传统 / 新零售」。对应分区视频还没到位时，会自动用父场景视频代替（不影响演示）。
- **声音规则**：看视频时有声；一进数字人接待，背景视频静音（避免和语音播报打架）。

## 四、给客户打包分发（演示交付）

1. 把 `dify-frontend/deploy/` **整个文件夹**压缩成 zip 发给客户（本指南已附在包内）。
2. **客户机器要求**：
   - Windows 系统；
   - **已安装 Chrome**（推荐，保证视频自动带声播放）；
   - 能访问 `.env.local` 里 `DIFY_API_BASE` 指向的 Dify 地址（数字人问答需要联网；**视频和场景切换不依赖网络，断网也能演示**）。
3. **如果客户的 Dify 地址和密钥不同**：
   让客户用记事本打开 `deploy/.env.local`，改这两行即可：
   ```
   DIFY_API_BASE=http://客户Dify地址:端口/v1
   DIFY_API_KEY=app-客户自己的Key
   ```
4. 客户解压后**双击 `start.bat`** 即可演示，步骤同上。

> ⚠️ **重要提醒（数字人问答能否用）**
> 当前包内预填的 `DIFY_API_BASE` 是**你们公司的内网地址**（zkt.medlibbot.com:8380）。
> - 客户机和它**在同一现场网络 / 能访问该地址** → 数字人问答直接可用。
> - 客户机**连不上该地址** → 视频、场景切换照常演示，但点「开始互动」后数字人**不会有回答**。这种情况需按上一步把地址改成客户自己的 Dify。

## 五、常见问题排查

| 现象 | 原因 | 解决办法 |
|------|------|----------|
| 双击后黑屏 / 打不开 | 3000 端口被别的程序占用（尤其之前跑过 dev） | 关掉占 3000 的程序，再双击 `start.bat` |
| `Application error: a client-side exception` | 部署包不完整 / 损坏 | 重新解压最新的包（不要部分覆盖旧包） |
| 数字人问答没回复 | 客户机访问不到 `DIFY_API_BASE` 或 Key 错 | 检查网络连通性；核对 `.env.local` 的地址和 Key |
| 视频没声音 | 没用 Chrome 打开 | 脚本已自动用 Chrome 并允许自动播放；用其他浏览器会自动带声受限 |
| 麦克风没反应 | 首次用语音，浏览器请求麦克风权限被拒 | 允许麦克风权限后重试 |

## 七、改代码后如何重新出包（给维护者）

1. 在 `dify-frontend/` 改完代码；
2. 停掉所有占用 3000 的服务；
3.  Clean 重建：`rm -rf .next` → `npm run build`（已开 `output:'standalone'`）；
4.  **整体重建** deploy（务必先删旧产物再整体拷，避免混版本）：
   ```
   rm -rf deploy/.next deploy/public
   cp -r .next/standalone/. deploy/
   cp -r .next/static deploy/.next/static
   cp -r public/. deploy/public/
   ```
5.  用 curl 把首页每个 `/_next/static/*.js|css` 逐个验 200，**光看首页 200 不够**（曾因静态 chunk 404 导致 client-side exception）。

## 八、换数字人形象（不用改代码、不用重新 build）

> 前端已固定引用 `public/avatar.png`（`page.tsx` 里写死 `/avatar.png`），**换形象只需替换这一个文件**，无需动代码、无需 `npm run build`。

**准备新形象图（去白底）：**
1. 把任意白底数字人图片放到项目根目录（如 `DigitalHuaman.png`）；
2. 运行一键去背：
   ```
   python tools/remove_bg.py [图片路径]
   ```
   自动输出透明 PNG 到 `dify-frontend/public/avatar.png`（人物保留、白底变透明，保留原有光环/辉光/浮动/说话发光等动画）。

**本地预览（dev 模式）：**
- 覆盖 `public/avatar.png` 后，浏览器刷新 `localhost:3000` 即生效（热更新）。

**发给客户（deploy 包）：**
- 把去背后的 `public/avatar.png` **同时复制到 `deploy/public/avatar.png`**（一次文件复制，不是 build），双击 `start.bat` 即新形象。
- 包内 `.env.local`、`.next/` 等都不用动。

> 注意：deploy 包里的 `public/` 是 build 时复制进去的；改了 `public/avatar.png` 后**只需同步这一个文件到 `deploy/public/`**，千万别只改源码 public 却忘了同步到 deploy 包，否则客户看到还是旧形象。
