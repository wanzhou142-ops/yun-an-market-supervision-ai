# 云安市场监管大屏 · 客户现场语音部署保底方案

> 适用场景：客户现场 **一台 Windows 电脑同时连接大屏 + 麦克风**，浏览器与语音服务同机运行。
> 目标：保留「语音唤醒」体验，同时做到**任何一层失效都有兜底**，公共大屏体验不中断。
> 状态：本文为**部署/验收方案**（暂未改动代码），后续按 §9 进入实施。

---

## 0. 结论先行（给对接人看）

1. **设备形态已确认可行**：单台电脑连大屏 + 麦 → 浏览器和语音服务同机，`localhost` 收麦成立，不存在「分机失效」风险。
2. **方案核心 = 三层保底**：
   - 第 1 层：自适应 VAD 阈值 + 首启自动校准（应对不同现场噪音）
   - 第 2 层：半双工锁（防回声自激）+ 关键词兜底（唤醒词没抓到也能导航）
   - 第 3 层：触摸导航永远可达（标签 + 分区按钮，已具备）
3. **当前最大缺口 = 部署包没有语音后端**：现有 `deploy/` 只含前端，必须补齐 `voice-service` + Python 运行时 + 模型，并让一键启动同时拉起前后端。
4. **现场可调参数必须外置**：当前阈值写死在代码里，需改为读 `.env` 配置，到现场改一个数字即可，不必动代码。

```
┌─────────────── 客户工控机 / Windows 电脑 ───────────────┐
│                                                          │
│   Chrome (全屏, localhost:3000)  ←── 大屏 (HDMI)          │

│        │   /api/voice/* 转发                             │

│        │                                                 │
```

## 3. 硬件规格建议

| 项目 | 建议 | 不推荐 |
|---|---|---|
| 麦克风类型 | **近讲 / 指向性 USB 麦克风**（如会议麦、播音麦） | 一体机/工控机自带麦（拾音差、易啸叫） |
| 放置位置 | 距交互点 **0.5~1 米**，麦**背对**大屏音响 | 正对喇叭（必回声自激） |
| 增益 | Windows 声音设置里麦克风级别拉到 80~100 | 默认 50 且离人 1 米外 |
| 备用 | 若现场远场唤醒率 < 60%，降级为「按住说话」按钮（见 §5.4） | — |

> 理由：Vosk small 模型对弱信号识别率有限，硬件拾音能力直接决定体验上限。

## 4. 配置项（现场可调，不动代码）

> 当前 `voice.ts` 的阈值写死为函数内 `const`（`ABS_FLOOR=0.008` / `*2.2` / `*1.6`，见 `lib/voice.ts:247,283,284`）。
> 需改为读取 `process.env.NEXT_PUBLIC_VAD_*`，失败时回退当前值。这样现场只改 `.env` 一个数字。

建议在 `.env.local`（及 `.env.local.example`）新增：

```ini
# ── VAD 灵敏度（现场按噪音级别调整，详见下表）──
NEXT_PUBLIC_VAD_ABS_FLOOR=0.008   # 触发/结束的绝对下限；越小越灵敏
NEXT_PUBLIC_VAD_START_MULT=2.2    # 阈值 = max(底噪 × 此值, ABS_FLOOR)
NEXT_PUBLIC_VAD_END_MULT=1.6      # 静音判定 = max(底噪 × 此值, ABS_FLOOR)
NEXT_PUBLIC_VAD_GRACE_MS=400      # 启动宽限期（测底噪 + 避开头爆音）
NEXT_PUBLIC_VAD_WAIT_MS=6000      # 一直没声超过此值 → 自动取消
```

**现场参数速查表**（首启校准后据此微调）：

| 现场环境 | ABS_FLOOR | 说明 |
|---|---|---|
| 安静（会议室/办公室级） | 0.012（原值） | 中青年正常音量稳 |
| **中等（人流可控，偶有交谈）** | **0.008（已用）** | 老年观众/轻声/儿童可用 |
| 嘈杂（开放展馆/儿童多/回声大） | 0.015~0.020 | 提高抗噪，避免背景声误触发 |
| 远场（人站 1~3 米） | 需先测底噪再定 | 配合近讲麦，否则降级为按键 |

> voice-service 侧已支持 env（`server.py`）：`VOICE_SERVICE_PORT / ASR_BACKEND / TTS_BACKEND / VOSK_MODEL / PIPER_MODEL`，打包时固定即可。

## 5. 必须实现的健壮性代码（保底核心）

按优先级排序，每项给「位置 / 改法 / 验收」。

### 5.1 半双工锁（防回声自激）— 最高优先级
- **位置**：`lib/voice.ts` 的 `startListening()` / `speak()`
- **问题**：TTS 播报期间麦克风仍在收声，大音量喇叭下会把数字人自己的声音吃进去反复触发。
- **改法**：维护全局 `tts.playing` 标志；`startListening()` 开头 `if (tts.playing) return`；`speak()` 播完才清除。返回视频模式时强制停 TTS。
- **验收**：播放「欢迎来到…」时对着麦说话，调试面板**不出现** `检测到人声`。

### 5.2 自适应阈值 + 首启自动校准
- **位置**：`lib/voice.ts` VAD 初始化段（`voice.ts:251-283`）
- **改法**：首次启动静默 1 秒测现场底噪 RMS，`ABS_FLOOR` 取 `底噪 × K`（K 见 §4 表）；阈值改为 `max(噪声Floor × mult, 配置下限)`。
- **验收**：不同现场改一个数字即生效，无需重新编译。

### 5.3 关键词兜底（唤醒词没抓到也能导航）
- **位置**：`page.tsx` 的 `classify()` 意图识别
- **问题**：Vosk 常把「安安」认成「广/唉」，而导航几乎全靠抓到「安安」——单点故障。
- **改法**：即使没抓到唤醒词，只要 ASR 文本含「宣传廊/药店/返回/迎宾」等**导航词**，照样执行导航；命中导航词时**不要求**先唤醒。
- **验收**：说「去宣传廊」（不喊安安）也能切场景。

### 5.4 「没听清」重试 + 触摸兜底
- **位置**：`page.tsx` ASR 结果为空 / 无意图分支
- **改法**：屏上提示「没听清，请再说一遍，或点这里选择」+ 直接展示可点场景按钮；连错 2 次自动退回声波引导。
- **验收**：不说话直接点「开始互动」→ 6 秒后屏上出现可点按钮，体验不断。

> 以上 4 项 **不依赖提前知道现场**，属「通用健壮性」。触摸导航（标签+分区按钮）已具备，是永远的保底底线。

## 7. 现场故障排查速查

| 现象 | 可能原因 | 现场处理 |
|---|---|---|
| 点「开始互动」无反应 | 麦克风权限未授权 | Chrome 地址栏左侧 🔒 → 允许麦克风；或 `chrome://settings/content/microphone` |
| 一直「未检测到人声」 | 阈值过高 / 离麦太远 / 麦增益低 | 调低 `NEXT_PUBLIC_VAD_ABS_FLOOR`；靠近麦；Win 麦克风级别拉到 100 |
| 频繁误触发（识别错句） | 阈值过低 / 环境噪 | 调高 `ABS_FLOOR` 至 0.015~0.020 |
| 回声自激（自己跟自己聊） | 半双工锁未生效 | 确认 §5.1 已实现；麦背对喇叭 |
| `/api/voice/health` 不可达 | 语音服务没起 | 检查 `start.bat` 是否拉起 voice-service；看其日志端口 8000 |
| TTS 不出声 | Piper 模型损坏（曾 15 字节空壳） | 校验 `zh_CN-huayan-medium.onnx` ≥ 60MB；否则重新下载 |
| 识别率整体差 | Vosk small 模型上限 | 现场加近讲麦；或降级为「按住说话」按钮 |
