# 共享知识库

普法内容的**唯一源文件**目录。小智机器人导入此处合并 txt 做 RAG 与问学考；大屏当前不接知识库（见 `big-screen/frontend/app/page.tsx`）。

## 目录

| 子目录 / 文件 | 内容 | 用途 |
|--------|------|------|
| `zones/` | 各展区知识 docx、安安机器人考题 docx | 源文件；改 docx 后需重新合并 |
| `regulations/` | 法规占位 txt（四部法全文） | 开发期占位；Dify 可直接用 |
| **`小智问学考知识库合集.txt`** | 法规篇 + 固定考题库合并 | **小智平台单文件上传（推荐）** |
| `法规篇知识库合集.txt` | 仅三区法规篇 | 教 / 学 审阅用 |
| `考题知识库合集.txt` | 选择题 50 + 判断题 50 | 考 审阅用 |
| `scripts/merge_law_kb.py` | 法规篇合并 | 单独生成法规篇 |
| `scripts/merge_exam_kb.py` | 考题 docx 解析 | 单独生成考题库 |
| `scripts/merge_xiaozhi_kb.py` | 法规 + 考题合并 | **一键生成上传物** |

### 小智平台单文件上传

小智平台知识库**只能上传一个文件**。按 XMind 与模式分区，合并为：

```
小智问学考知识库合集.txt
├── 第 1–3 部分 · 教 / 学 · 法规篇
│   ├── 化妆区 ← zones/化妆品展区-法规篇.docx
│   ├── 药品区 ← zones/药品展区-法规篇.docx
│   └── 医疗器械区 ← zones/医疗器械展区-法规篇.docx
├── 第 4 部分 · 考 · 选择题题库（50 题）
│   └── zones/安安机器人考题-选择题.docx
└── 第 5 部分 · 考 · 判断题题库（50 题）
    └── zones/安安机器人考题-判断题.docx
```

| 模式 | 使用分区 | 行为 |
|------|----------|------|
| 教 | 第 1–3 部分 | 法规问答，引用法条 |
| 学 | 第 1–3 部分 | 通俗讲解，引用法条 |
| 考 | 第 4–5 部分 | 从固定题库抽 3 选择 + 2 判断，按【标准答案】判分 |

**维护**：修改 `zones/` 下任意源 docx 后执行：

```bash
python shared/knowledge-base/scripts/merge_xiaozhi_kb.py
```

然后在小智平台重新上传 `小智问学考知识库合集.txt`，并同步角色介绍（见 `xiaozhi/dify/prompts/小智平台问学考提示词.md`）。

## 维护规则

1. **源文件只在这里改**，不在 `big-screen/` 或 `xiaozhi/` 里各存一份。
2. 更新后在小智平台重新导入/同步向量库。
3. 大屏若无知识问答需求，无需同步。

## 考题源文件

- **唯一源**：`zones/安安机器人考题-选择题.docx`、`zones/安安机器人考题-判断题.docx`
- `xiaozhi/question-bank/` 中为历史副本或 demo，**以 `shared/knowledge-base/zones/` 为准**
