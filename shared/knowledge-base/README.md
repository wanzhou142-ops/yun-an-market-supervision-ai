# 共享知识库

普法内容的**唯一源文件**目录。小智机器人导入此处 docx 做 RAG 与问学考；大屏当前不接知识库（见 `big-screen/frontend/app/page.tsx`）。

## 目录

| 子目录 / 文件 | 内容 | 用途 |
|--------|------|------|
| `zones/` | 各展区知识 docx（序厅、药品、化妆品、医疗器械、模拟药店等） | 源文件；改 docx 后需重新合并 |
| `regulations/` | 法规占位 txt（四部法全文） | 开发期占位；Dify 可直接用 |
| **`法规篇知识库合集.txt`** | 三区法规篇 docx 按 XMind 结构合并 | **小智单文件上传（推荐）** |
| `scripts/merge_law_kb.py` | 合并脚本 | 更新 docx 后重新生成合集 |

### 小智平台单文件上传（法规篇）

小智平台知识库**只能上传一个文件**。按 XMind 导图结构，将三区「法规篇」合并为：

```
法规篇知识库合集.txt
├── 第 1 部分 · 化妆区 · 法规篇      ← zones/化妆品展区-法规篇.docx
├── 第 2 部分 · 药品区 · 法规篇      ← zones/药品展区-法规篇.docx
└── 第 3 部分 · 医疗器械区 · 法规篇  ← zones/医疗器械展区-法规篇.docx
```

对应 XMind 路径：`宣传廊 → {化妆区|药品区|医疗器械展区} → 法规篇 → 展区知识库`；综合培训区「教 / 学」模式共用此合集。

**维护**：修改 `zones/*-法规篇.docx` 后执行：

```bash
python shared/knowledge-base/scripts/merge_law_kb.py
```

然后在小智平台重新上传 `法规篇知识库合集.txt`。

## 维护规则

1. **源文件只在这里改**，不在 `big-screen/` 或 `xiaozhi/` 里各存一份。
2. 更新后在小智平台重新导入/同步向量库。
3. 大屏若无知识问答需求，无需同步。

## 与小智题库的区别

- `zones/`：展区普法知识（RAG 问答）
- `xiaozhi/question-bank/`：安安机器人考题（选择/判断），专用于问学考
