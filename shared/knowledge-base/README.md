# 共享知识库

普法内容的**唯一源文件**目录。小智机器人导入此处 docx 做 RAG 与问学考；大屏当前不接知识库（见 `big-screen/frontend/app/page.tsx`）。

## 目录

| 子目录 | 内容 | 用途 |
|--------|------|------|
| `zones/` | 各展区知识 docx（序厅、药品、化妆品、医疗器械、模拟药店等） | 导入小智/Dify |
| `regulations/` | 法规占位 txt | 开发期占位，正式以 docx 为准 |

## 维护规则

1. **源文件只在这里改**，不在 `big-screen/` 或 `xiaozhi/` 里各存一份。
2. 更新后在小智平台重新导入/同步向量库。
3. 大屏若无知识问答需求，无需同步。

## 与小智题库的区别

- `zones/`：展区普法知识（RAG 问答）
- `xiaozhi/question-bank/`：安安机器人考题（选择/判断），专用于问学考
