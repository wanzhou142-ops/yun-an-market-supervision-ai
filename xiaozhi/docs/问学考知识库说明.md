# 小智平台「问学考」知识库说明

> 用途：为云安区市场监管综合培训法治教育基地的小智语音机器人，提供「教 / 学 / 考」三种互动模式所需的资料支撑。
> 性质：**开发期占位知识库**，正式上线前必须替换为客户确认的现行有效版本。

---

## 一、知识库是什么（一句话）

一份合并上传的纯文本知识库 [`小智问学考知识库合集.txt`](../../shared/knowledge-base/小智问学考知识库合集.txt)，包含**法规篇（教 / 学）**和**固定考题库（考）**两个分区。三种模式的区别靠**系统提示词（角色设定）**切换，并限定各自只读对应分区。

---

## 二、内容构成

| 分区 | 内容 | 题量 / 规模 | 对应模式 |
|------|------|-------------|----------|
| 第 1–3 部分 · 法规篇 | 化妆区 / 药品区 / 医疗器械区法规 docx 合并 | 约 5 万字 | 教、学 |
| 第 4 部分 · 选择题库 | `zones/安安机器人考题-选择题.docx` | 50 题 | 考 |
| 第 5 部分 · 判断题库 | `zones/安安机器人考题-判断题.docx` | 50 题 | 考 |

每道考题含结构化字段：`【题号】【题型】【题干】【选项】【标准答案】【解析】`（解析字段判断题必有或可选）。

**源文件位置**：[`shared/knowledge-base/zones/`](../../shared/knowledge-base/zones/)

**生成命令**：

```bash
python shared/knowledge-base/scripts/merge_xiaozhi_kb.py
```

## 三、教 / 学 / 考 三模式如何用

### 教（问答模式，默认）
- **作用**：参观者随口提问，机器人即时解答。
- **资料范围**：仅第 1–3 部分法规篇。
- **典型问法**：「什么是特殊化妆品？」「化妆品标签不能写什么？」

### 学（讲解模式）
- **作用**：围绕主题系统普法讲解。
- **资料范围**：仅第 1–3 部分法规篇。
- **典型触发**：「我想了解一下化妆品标签的规定」

### 考（考核模式）
- **作用**：从固定题库抽题测验，逐题判分。
- **资料范围**：仅第 4–5 部分考题库。
- **考试结构**：每次 **3 道选择题 + 2 道判断题**，共 5 题。
- **出题规则**：原样读出题库【题干】【选项】，**禁止自编或从法规现场生成**。
- **判分规则**：只对照【标准答案】；答错可读【解析】。
- **典型触发**：「我要考试」「考考我」

## 四、小智平台接入建议

### 1. 知识库本体
- 上传 **`小智问学考知识库合集.txt`**（仅此一个文件）。
- 检索方式选**向量 / 混合检索**（不要选纯关键词）。

### 2. 角色介绍
- 使用 [`xiaozhi/dify/prompts/小智平台问学考提示词.md`](../dify/prompts/小智平台问学考提示词.md) 中的**总控版角色介绍**。
- 关键约束：教 / 学禁止引用考题库；考禁止自编题目；禁止向用户说「从知识库知道的」。

### 3. 模型选择
- 展厅实时对话，优先选非推理模型（如 DeepSeek-V3），响应快。
- 推理模型延迟高，语音体验差。

---

## 五、检索要点

1. **索引模式**：高质量或混合检索。
2. **TopK**：建议 5。
3. **分区隔离**：靠提示词限定模式只读对应部分；合并后文件略大（约 6 万字），一般可接受。
4. **教 / 学引用**：回答应带「依据《XX》第 X 条」。

---

## 六、注意事项（上线前必查）

- **占位性质**：法规与考题均为开发期占位，正式前须替换为客户确认版本。
- **考模式准确性**：务必限定「只从第 4/5 部分抽题 + 按标准答案判分」，避免模型用训练数据自创考点。
- **考题维护**：改 docx 后重新跑 `merge_xiaozhi_kb.py` 并重新上传。

---

## 七、与 Dify 版本的关系

- Dify 侧仍可使用 `regulations/` 下四部法 txt 或展区 docx。
- 小智侧使用本仓库生成的 `小智问学考知识库合集.txt`（含法规篇 + 固定考题）。
- 两端内容源不同步时，以 `shared/knowledge-base/` 为唯一真相源，分别重新生成各自上传物。
